# Where the library comes from

Every movement in this library was written for OpenPilates in our own words. Before 0.4.0 each one was checked against the references below: does the movement exist under this name, what else is it called, and what springs do other teachers use. Where the references disagreed, the majority won.

Each movement file has a `sources` list with the ids of the references that name it. A movement that no reference names is not shipped (it is marked `retired`).

This is a cross-check of names and spring ranges, not a guarantee. Set-up, cues, muscles, levels and timings are still drafts until a qualified instructor reviews them.
